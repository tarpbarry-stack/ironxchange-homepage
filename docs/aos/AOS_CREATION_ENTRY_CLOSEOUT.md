# AOS Creation Entry Unification — Closeout Criteria

The build is complete when:

- container `+` remains client-only until Save;
- manual Save cannot succeed without Object + Passport + TRAN$ACT receipt;
- Object Studio uses the same browser provisioning receipt after optional explicit Definition resolution;
- Bulk/Excel remains an authoritative IX-Core job with row-level idempotency and Object/Passport receipts;
- trusted API/Chat use the signed server boundary and the same canonical receipt validator;
- no creation channel derives business meaning from display names;
- a retry cannot create a second permanent Object for the same intent;
- CI guards the convergence points so future code cannot casually reintroduce a parallel permanent create path.
